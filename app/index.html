Angka Indonesia — ringkasan data publik untuk dibaca cepat.

Angka-angka di situs ini dirangkum dari publikasi Badan Pusat Statistik (BPS), Sakernas, dan Kementerian Kesehatan. Situs ini bukan situs resmi BPS; periksa halaman Sumber data untuk rujukan tiap angka.

Seluruh halaman, grafik, dan tabel di situs ini dimuat dari file lokal — tidak ada permintaan jaringan.
